# کودک‌لرن TV

این پروژه یک اپ Android TV ساده برای باز کردن https://app.koodaklearn.com/ به‌صورت تمام‌صفحه است.

## گرفتن APK در Android Studio
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را اجرا کنید.
4. فایل APK معمولاً در مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

## نصب روی فیلیمو باکس
فایل APK را با فلش یا برنامه انتقال فایل به فیلیمو باکس منتقل کنید و نصب نمایید.
در صورت نیاز، اجازه Install unknown apps را برای فایل‌منیجر فعال کنید.

## نکته
این نسخه اولیه است. عملکرد دقیق دکمه‌های ریموت داخل خود صفحه به نحوه طراحی وب‌اپ کودک‌لرن بستگی دارد.
